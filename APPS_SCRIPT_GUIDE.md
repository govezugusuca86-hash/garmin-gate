# Гайд: разворачиваем Apps Script для приёма заказов

Этот гайд проведёт от «нет ничего» до «заказы летят в Google Sheets + Telegram».
Время на всё: **15-20 минут**.

⚠️ **Безопасность:** токен бота, который ты получишь от BotFather — секретный.
С ним можно отправлять сообщения от имени твоего бота. Никому не показывай его,
не выкладывай на GitHub, не вставляй в публичные чаты.

---

## ШАГ 1. Создаём Telegram-бота

1. Открой в Telegram бота **[@BotFather](https://t.me/BotFather)**.
2. Напиши команду:
   ```
   /newbot
   ```
3. BotFather спросит **имя бота** (display name) — напиши, например:
   ```
   Neogar Orders
   ```
4. Затем спросит **юзернейм** — должен оканчиваться на `bot`. Например:
   ```
   neogar_orders_bot
   ```
   Если занято — попробуй с цифрой: `neogar_orders_2026_bot`.

5. BotFather пришлёт сообщение с токеном:
   ```
   Use this token to access the HTTP API:
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

   **Скопируй и сохрани этот токен.** Он понадобится в шаге 3.

6. **Очень важно:** открой своего бота (BotFather пришлёт ссылку `t.me/neogar_orders_bot`)
   и напиши ему любое сообщение — например `/start`.

   Без этого бот не сможет отправить тебе ни одного сообщения. Это защита Telegram
   от спама: бот может писать только тем, кто первым ему написал.

   Твой `chat_id` уже известен: **`8306869104`** (ты сказал в чате).

---

## ШАГ 2. Создаём Google Sheets

1. Открой https://sheets.google.com (зайди под нужным аккаунтом Google).
2. Создай новую таблицу: **Создать → Пустая таблица**.
3. Назови её, например: **«Neogar — Заказы»**.

Таблица будет пустой — это нормально. Лист «Заказы» создастся автоматически
при первом заказе.

---

## ШАГ 3. Открываем Apps Script и вставляем код

1. В открытой таблице: **Расширения → Apps Script**.

   Откроется новая вкладка с редактором Apps Script. Там будет файл `Код.gs`
   (или `Code.gs`) с пустой функцией `function myFunction() {}`.

2. **Выдели весь существующий код** в редакторе (Ctrl+A) и **удали** его (Delete).

3. Открой файл `Code.gs` из билда (распакованного `garmin-gate-v2.zip`).
   Скопируй **всё содержимое** в очищенный редактор Apps Script.

4. **Подставь свои данные.** В самом верху файла найди:
   ```js
   var TELEGRAM_BOT_TOKEN = '';
   var TELEGRAM_CHAT_ID   = '';
   ```

   И замени на:
   ```js
   var TELEGRAM_BOT_TOKEN = '7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxx';
   var TELEGRAM_CHAT_ID   = '8306869104';
   ```

   (вместо `7123456789:AAH...` — твой реальный токен из шага 1)

5. Сохрани файл: **Ctrl+S** (или иконка дискеты вверху).

6. Apps Script может попросить дать проекту имя. Назови, например:
   **«Neogar Orders»**.

---

## ШАГ 4. Проверяем Telegram-уведомления

В файле есть готовая функция `testTelegram` — она отправляет тестовое сообщение,
чтобы убедиться, что токен и chat_id правильные.

1. В верхней панели редактора найди выпадающий список функций (рядом с кнопкой
   «Выполнить» ▶). Сейчас там, скорее всего, выбрано `doPost`.

2. Кликни на список и выбери: **`testTelegram`**.

3. Нажми кнопку **▶ Выполнить**.

4. Apps Script впервые запросит разрешения:
   - «Авторизация требуется» → **Просмотреть разрешения**.
   - Выбери свой Google-аккаунт.
   - Появится экран «Google не подтвердил это приложение» (это нормально,
     потому что приложение твоё личное):
     - Нажми **Дополнительные настройки** (Advanced).
     - Внизу: **Перейти к проекту "Neogar Orders" (небезопасно)**.
   - Разреши доступ к Google Sheets и подключению к внешним сервисам.

5. После авторизации функция выполнится. В Telegram должно прийти:
   ```
   🛒 ТЕСТ
   Если видишь это сообщение — Telegram-уведомления работают.
   ```

**Если сообщение не пришло:**
- Проверь, что ты написал боту `/start` в Telegram (см. шаг 1, пункт 6).
- Проверь токен — скопирован ли он целиком, без лишних пробелов.
- Открой **Журнал выполнения** (View → Logs или Ctrl+Enter) — там будет ошибка.
  Часто бывает `400 Bad Request: chat not found` — значит ты не написал боту.

## ШАГ 5. Развёртываем как веб-приложение

Теперь нужно сделать так, чтобы сайт мог отправлять заказы на этот скрипт.
Для этого превращаем скрипт в публичный URL.

1. В правом верхнем углу: **Развернуть → Новое развёртывание** (Deploy → New deployment).

2. Откроется окно. Кликни на ⚙️ (шестерёнка) рядом с «Выберите тип» → выбери
   **Веб-приложение** (Web app).

3. Заполни поля:
   - **Описание** (опционально): `Neogar orders webhook v1`.
   - **Выполнять от имени:** `Я (твой@gmail.com)`.
   - **У кого есть доступ:** **`Все`** (Anyone).

   ⚠️ Это критично: если выбрать «Все, у кого есть аккаунт Google» — сайт
   не сможет отправить заказ, потому что клиенты не авторизованы.

4. Нажми **Развернуть**.

5. Apps Script покажет:
   - **Идентификатор развёртывания** — не нужен.
   - **URL веб-приложения** — вот это нужно. Выглядит так:
     ```
     https://script.google.com/macros/s/AKfycby...XYZ123/exec
     ```

   **Скопируй этот URL.**

6. Нажми **Готово**.

---

## ШАГ 6. Проверяем URL в браузере

1. Открой скопированный URL в новой вкладке браузера.
2. Должно вернуть JSON:
   ```json
   {"ok":true,"service":"neogar-orders"}
   ```

Если видишь это — всё работает.

**Если вместо JSON показывает экран «Войти в Google»:**
Значит при развёртывании выбран не тот доступ. Вернись в Apps Script:
**Развернуть → Управление развёртываниями → ✏️ → У кого есть доступ: Все →
Развернуть**.

---

## ШАГ 7. Подставляем URL в js/app.js

1. Открой `js/app.js` в проекте.
2. Найди строку (около строки 91):
   ```js
   window.ORDER_WEBHOOK_URL = 'https://script.google.com/macros/s/REPLACE_ME/exec';
   ```
3. Замени её на свой URL из шага 5:
   ```js
   window.ORDER_WEBHOOK_URL = 'https://script.google.com/macros/s/AKfycby...XYZ123/exec';
   ```
4. Сохрани файл.

---

## ШАГ 8. Заливаем сайт на GitHub

```bash
git add -A
git commit -m "checkout form + google sheets + telegram"
git push
```

GitHub Pages обновится через 1-2 минуты.

## ШАГ 9. Тестируем боевой заказ

1. Открой свой сайт https://neogar.ru.
2. Добавь любой товар в корзину.
3. Перейди в корзину → нажми **«Оформить заказ»**.
4. Заполни форму:
   - ФИ: `Тестовый Тест`
   - Телефон: `+79991234567`
   - Email (необязательно): `test@test.ru`
   - Галочка «Нужна доставка» — можешь поставить или не ставить.
5. Нажми **«Оформить заказ»**.

Должно произойти:
- В Telegram прилетит уведомление о заказе `NEO-0001`.
- В Google Sheets появится строка с заказом.
- Тебя перекинет на страницу успеха с номером.

**Если страница успеха показала номер `NEO-XXXX-TMP`** — значит сайт не смог
связаться с Apps Script. Проверь URL в `app.js`, проверь что развёртывание
работает (шаг 6).

---

## Как обновлять код Apps Script

При любых правках в `Code.gs` нужно переразвернуть, чтобы изменения попали
в боевой URL:

1. **Развернуть → Управление развёртываниями** (Deploy → Manage deployments).
2. Кликни на иконку ✏️ (карандаш) рядом с активным развёртыванием.
3. **Версия** → выбери **«Новая версия»** (New version).
4. Нажми **Развернуть**.

**Важно:** URL при этом остаётся прежним. НЕ создавай каждый раз новое
развёртывание — каждое новое даёт новый URL, и сайт перестанет работать
с ним до обновления `app.js`.

## Что делать с Sheets

После первого заказа в таблице автоматически появится лист «Заказы» с колонками:

| Номер | Дата | ФИ | Телефон | Email | Тип | Способ | Город | Адрес | Товары | Кол-во | Сумма | Комментарий | UA | Referer |

Полезные советы:
- **Закрепи шапку:** Вид → Закрепить → 1 строку (уже закреплена кодом, но если что — вручную).
- **Включи уведомления о изменениях:** Инструменты → Уведомления → «Любое изменение → По электронной почте сразу». Это дополнительный канал на случай если TG-бот сломается.
- **Создай фильтр-вид «Новые заказы»:** Данные → Создать фильтр-вид → отсортируй по дате убыв.

## Лимиты Apps Script (бесплатные)

С твоим объёмом ты не упрёшься, но для справки:
- **6 минут** на одно выполнение скрипта (заказ выполняется за ~1-2 секунды).
- **20 000 вызовов внешнего API в день** (`UrlFetchApp.fetch` → Telegram). Для магазина это бесконечность.
- **30 сообщений в секунду** боту Telegram (тоже с огромным запасом).

Если когда-нибудь заказов станет тысячи в день — придётся переезжать на полноценный
бэкенд, но до того момента — далеко.

## Что делать если что-то сломалось

**Заказы не приходят в TG, но приходят в Sheets:**
- Открой Apps Script → **Выполнения** (Executions) в левом меню.
- Найди свежий запуск `doPost` → кликни на него → увидишь логи.
- Скорее всего там будет ошибка от Telegram API.

**Заказы не приходят никуда:**
- Открой свой Apps Script URL в браузере — должно вернуть JSON `{"ok":true...}`.
- Если возвращает HTML с формой входа → проверь доступ развёртывания (шаг 5).
- Если возвращает JSON, но заказы не идут — проверь URL в `js/app.js`.
- Открой сайт, F12 → Console → попробуй оформить заказ, смотри ошибки.

**Telegram пишет «401 Unauthorized»:**
- Токен неправильный. Проверь, что скопировал целиком.
- Или ты случайно отозвал токен через `/revoke` в BotFather.

**Telegram пишет «400 chat not found»:**
- Ты не написал боту первым. Открой бота в Telegram, нажми `/start`.
