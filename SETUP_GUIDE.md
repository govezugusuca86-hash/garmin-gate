# Neogar — настройка приёма заказов с нуля

Поток: сайт → Google Apps Script (вебхук) → Google Sheets (хранилище) → Telegram (опционально).

Не нужен ни сервер, ни хостинг кода, ни деньги. Только Google-аккаунт и (по желанию) Telegram-бот.

---

## Что вам понадобится

- Google-аккаунт (Gmail). Подойдёт любой, в том числе новый.
- 15 минут.
- Telegram-бот (опционально, для мгновенных уведомлений) — ещё 5 минут.

---

## Шаг 1. Создать Google-таблицу

1. Открыть https://sheets.google.com
2. Нажать **«+ Создать пустую таблицу»** (большой плюс слева внизу или кнопка «Blank»).
3. Переименовать таблицу (клик по «Untitled spreadsheet» вверху) — например, **«Neogar — заказы»**.
4. Лист (вкладка внизу) можно не трогать — Apps Script сам создаст лист с именем **«Заказы»** при первом заказе.

Готово. URL таблицы вида `https://docs.google.com/spreadsheets/d/ХХХХХ/edit` — её мы и будем использовать.

---

## Шаг 2. Открыть редактор Apps Script

1. В открытой таблице: верхнее меню **Расширения → Apps Script** (Extensions → Apps Script).
2. Откроется новая вкладка с редактором кода. Слева — файлы проекта, по умолчанию там один файл `Код.gs` (или `Code.gs`) с пустой функцией `myFunction()`.
3. Вверху можно переименовать проект (клик по «Untitled project») — например, **«neogar-orders»**.

---

## Шаг 3. Вставить код

1. В редакторе слева выбрать файл `Код.gs` (Code.gs).
2. **Выделить всё** содержимое (Ctrl/Cmd+A) и **удалить** (Delete).
3. Открыть файл `Code.gs` из архива (в корне репозитория). Скопировать **всё** содержимое (Ctrl/Cmd+A → Ctrl/Cmd+C).
4. Вставить в редактор Apps Script (Ctrl/Cmd+V).
5. **Сохранить**: иконка дискеты вверху или Ctrl/Cmd+S.

---

## Шаг 4. Установить стартовый номер заказа (NEO-0987)

Без этого шага первый заказ получит номер `NEO-0001`. Чтобы первый был `NEO-0987`:

**Вариант A — через настройки (одно действие):**

1. Слева в редакторе нажать иконку **⚙️ Project Settings** (Настройки проекта).
2. Прокрутить до **Script Properties** (Свойства скрипта).
3. **Add script property** (Добавить свойство).
4. Property: `lastOrderNumber`
5. Value: `986`
6. **Save script properties**.

**Вариант B — через запуск функции:**

1. В редакторе вверху, в выпадающем списке функций выбрать `setOrderCounter`.
2. Нажать **Run** (▶ Запустить).
3. Появится окно авторизации (см. шаг 6) — пройти его.
4. Готово. В логах (`View → Logs` или Ctrl/Cmd+Enter) увидите: `lastOrderNumber = 986 → next order: NEO-0987`.

Если хотите другой стартовый номер — откройте функцию `setOrderCounter` в коде и поменяйте `var N = 986` на нужное число (это значение последнего «выданного» номера; следующий заказ будет N+1).

---

## Шаг 5. Развернуть как веб-приложение

Это превращает скрипт в HTTP-эндпоинт, на который сайт сможет отправлять заказы.

1. Вверху справа кнопка **Deploy → New deployment** (Развернуть → Новое развёртывание).
2. В появившемся окне рядом с надписью «Select type» (Выберите тип) кликнуть **шестерёнку ⚙️** → выбрать **Web app** (Веб-приложение).
3. Заполнить:
   - **Description**: `neogar orders v1` (любая, для вас)
   - **Execute as**: **Me (ваш-email@gmail.com)** — выполнять от вашего имени
   - **Who has access**: **Anyone** (Все, включая анонимных) — обязательно, иначе сайт не сможет писать
4. Нажать **Deploy** (Развернуть).
5. Появится окно «Authorize access» (Авторизация). Нажать **Authorize access**.
6. Откроется окно выбора Google-аккаунта → выбрать ваш.
7. **«Google не подтвердил это приложение»** — это нормально, потому что это ваш собственный скрипт. Нажать **Advanced** (Дополнительно) → **Go to neogar-orders (unsafe)** (Перейти к проекту neogar-orders).
8. Запросит разрешения (Google Sheets + UrlFetch) → **Allow** (Разрешить).
9. Появится экран **Deployment successfully updated** с **Web app URL** вида:
   ```
   https://script.google.com/macros/s/AKfycby...очень-длинная-строка.../exec
   ```
10. **Скопировать этот URL.** Он понадобится на шаге 7.

---

## Шаг 6. (Если пропустили) Авторизация при первом запуске

Если в шаге 4 выбрали вариант B и Google запросил авторизацию — пройдите её точно так же, как описано в шаге 5 (пункты 5-8). Google спрашивает разрешения один раз на проект.

---

## Шаг 7. Прописать вебхук в коде сайта

1. Открыть файл `js/app.js` из репозитория (на GitHub или локально).
2. Найти строку:
   ```js
   window.ORDER_WEBHOOK_URL = 'https://script.google.com/macros/s/AKfycbz...exec';
   ```
3. Заменить URL на тот, что скопировали в шаге 5.
4. Сохранить, закоммитить, запушить в GitHub.
5. GitHub Pages развернёт изменение через 1-2 минуты.

---

## Шаг 8. Проверить, что всё работает

1. Открыть `neogar.ru` (или ваш GitHub Pages URL).
2. Добавить любой товар в корзину.
3. В корзине нажать **«Оформить заказ»**.
4. Должна открыться страница с номером (например, `NEO-0987`) и кнопками Telegram/MAX.
5. Открыть Google-таблицу → вкладка **«Заказы»** должна появиться автоматически с одной строкой.

Если строки нет — см. раздел «Если что-то не работает» в конце.

## Шаг 9. Telegram-уведомления (опционально)

Если хотите получать каждый заказ в Telegram в реальном времени:

### 9.1. Создать бота

1. В Telegram найти **@BotFather** (официальный бот, ищите галочку).
2. Отправить ему `/newbot`.
3. Придумать имя бота (любое, можно по-русски): например, `Neogar заказы`.
4. Придумать username бота — обязательно заканчивается на `bot`, например `neogar_orders_bot`.
5. BotFather пришлёт **токен** вида `7123456789:AAH...длинная-строка...`. Скопировать.

### 9.2. Узнать ваш chat_id

1. В Telegram найти **@userinfobot** (или @getmyid_bot, или @username_to_id_bot — любой).
2. Отправить ему `/start`.
3. Бот пришлёт ваш числовой ID, например `8306869104`.

### 9.3. Написать своему боту /start

Найти своего нового бота по username, который придумали в 9.1 (например, `@neogar_orders_bot`) и отправить ему **`/start`**. Без этого бот не сможет вам писать (правило Telegram).

### 9.4. Прописать токен и chat_id в Apps Script

1. Открыть редактор Apps Script (Расширения → Apps Script в таблице).
2. Вверху файла найти:
   ```js
   var TELEGRAM_BOT_TOKEN = '';
   var TELEGRAM_CHAT_ID   = '8306869104';
   ```
3. Заполнить:
   - `TELEGRAM_BOT_TOKEN` — токен из 9.1 в кавычках.
   - `TELEGRAM_CHAT_ID` — ваш ID из 9.2 в кавычках (если в коде уже стоит `8306869104` от прошлой настройки — замените на свой).
4. **Сохранить** (Ctrl/Cmd+S).
5. **Не нужно** заново разворачивать (Deploy) — изменения в коде применяются сразу для уже существующего веб-приложения. URL остаётся тот же.

### 9.5. Проверить уведомления

1. В редакторе вверху выбрать функцию `testTelegram`.
2. Нажать **Run** (▶).
3. В Telegram должно прийти сообщение «🛒 ТЕСТ — Если видишь это сообщение — Telegram-уведомления работают».

Если не пришло — см. раздел «Если что-то не работает».

## Когда придёт первый заказ — что вы увидите

### В Google Sheets
Колонки: `Номер заказа | Дата | Статус | ФИ | Контакт | Email | Доставка | Товары | Кол-во | Сумма | Комментарий | UA | Referer`

Поскольку форма убрана, у анонимных заказов:
- **Статус** = `⏳ Ждём сообщения`
- **ФИ** = `—`
- **Контакт** = `—`
- **Email** = пусто

Как только клиент напишет вам в Telegram/MAX с номером заказа — вручную меняйте статус в таблице (например, на `✅ Подтверждён` или `🚚 В сборке`). Это удобно отслеживать и фильтровать.

### В Telegram (если настроено)
```
🛒 НОВЫЙ ЗАКАЗ NEO-0987
━━━━━━━━━━━━━━━━━━━━
⏳ Ждём сообщения от клиента
Контакты не оставлены — клиент должен написать сам с номером заказа.

📦 Состав (2 шт.):
• Garmin Fenix 8 × 1 = 79 990 ₽
• Чехол силиконовый × 1 = 1 990 ₽

💰 Итого: 81 980 ₽
```

## Обновление кода в будущем

Если правите `Code.gs`:
1. Открыть редактор Apps Script.
2. Заменить код, сохранить.
3. **Изменения внутри функций применяются сразу.** Заново разворачивать НЕ нужно.

Если меняете формат данных (например, добавили колонку в HEADERS):
1. Сохранить код.
2. **Управление развёртываниями** (Manage deployments) → ✏️ редактирование → **Версия: Новая** → Развернуть.
3. URL остаётся тот же.

Если случайно поменялся URL (создали «New deployment» вместо редактирования) — пропишите новый URL в `js/app.js`.

## Если что-то не работает

### Заказ не появляется в таблице

1. **Проверить URL вебхука** в `js/app.js` — должен заканчиваться на `/exec`, не `/dev`.
2. **Открыть в браузере сам URL вебхука** — должно вернуться `{"ok":true,"service":"neogar-orders"}`. Если ошибка — деплой битый, переразверните (Deploy → Manage deployments → Edit → New version).
3. **Открыть консоль браузера** на странице корзины (F12 → Console), нажать «Оформить заказ» и посмотреть ошибки. Если видите CORS/network — проверьте, что в Deploy выбрано «Who has access: Anyone».
4. **Заглянуть в логи Apps Script**: редактор → слева иконка часов «Executions» (Запуски). Видны все вызовы и ошибки.

### Telegram-уведомления не приходят

1. Запустите `testTelegram` из редактора — посмотрите ошибку в логах.
2. **Самая частая причина**: вы не написали боту `/start` (шаг 9.3). Бот не может первым написать пользователю, пока пользователь сам не начал с ним диалог.
3. Проверьте, что `TELEGRAM_CHAT_ID` — это число, не username. Username вида `@vasya_neogar` не подходит — нужен числовой ID от @userinfobot.
4. Проверьте, что в токене нет лишних пробелов/кавычек.

### Номера заказов идут не с NEO-0987

1. Откройте Script Properties (⚙️ Project Settings → Script Properties).
2. Если `lastOrderNumber` нет — нажмите Add property, значение `986`.
3. Если есть, но с другим числом — отредактируйте на `986`.
4. Альтернатива: запустить функцию `setOrderCounter` (внутри уже стоит `986`).

### «Authorization required» при каждом запуске

Это нормально для самого первого Run. После первой авторизации больше не спросит.

### Хочу сбросить счётчик дублей (для тестирования)

В редакторе можно запустить:
```js
function clearDedup() {
  var props = PropertiesService.getScriptProperties();
  var all = props.getProperties();
  for (var k in all) {
    if (k.indexOf('dedup_') === 0) props.deleteProperty(k);
  }
}
```

---

## Что не делать

- ❌ **Не делиться URL вебхука публично.** Любой, кто его знает, сможет создавать пустые заказы. Это не катастрофа (есть honeypot и дедупликация), но репутацию засорить можно.
- ❌ **Не редактировать колонки в таблице во время приёма заказов.** Если хотите добавить колонку — добавьте справа от существующих, не сдвигайте.
- ❌ **Не удалять лист «Заказы».** Если удалили — он пересоздастся при следующем заказе, но старые данные пропадут.
