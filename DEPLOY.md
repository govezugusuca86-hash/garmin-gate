## Шаг 1 — Apps Script

1. Открой Google Sheets → создай новую таблицу (или открой существующую).
2. Расширения → Apps Script.
3. Удали всё, что там есть, вставь содержимое `Code.gs`, сохрани (Ctrl+S).
4. Развернуть → Новое развёртывание → ⚙ Тип → Веб-приложение.
   - Выполнять от имени: «Я».
   - Доступ: «Все».
5. Скопируй URL развёртывания (вида `https://script.google.com/macros/s/AKfy.../exec`).
6. Проверь: открой этот URL в браузере → должен вернуть `{"ok":true,"service":"neogar-orders"}`.

## Шаг 2 — Подставить URL в js/app.js

Открой `js/app.js`, найди строку:

```js
window.ORDER_WEBHOOK_URL = 'https://script.google.com/macros/s/REPLACE_ME/exec';
```

И замени `REPLACE_ME` (или весь URL) на скопированный.

## Шаг 3 — Залить в репозиторий

Закоммить все файлы из этого билда (КРОМЕ `Code.gs` и `DEPLOY.md` — они в репозиторий не нужны,
`Code.gs` живёт в Apps Script, эта инструкция — где удобно).

В корне репозитория `Code.gs` всё-таки оставь, если хочешь, чтобы код был версионирован
(но он не будет автоматически синхронизироваться с Apps Script — это две независимые копии).

GitHub Pages подхватит изменения автоматически через 1-2 минуты.

## Шаг 4 — Цели в Яндекс Метрике (опционально)

Если хочешь видеть конверсию, заведи в Метрике (счётчик 108563480) цели:
- `order_vk` — клик по кнопке «Оформить заказ» в корзине (уже срабатывает)
- `order_submit` — успешная отправка формы
- `order_success_view` — просмотр страницы успеха

## Шаг 5 — Обновление Apps Script

При изменении `Code.gs` нужно создать новую версию развёртывания:
Развернуть → Управление развёртываниями → ✏️ рядом с активным → Версия: «Новая» → Развернуть.
URL при этом не меняется, новый деплой не нужен.

## Что произойдёт при заказе

1. Пользователь жмёт «Оформить заказ» в корзине → попадает на `checkout.html`.
2. Заполняет форму (ФИ обязательно, телефон или email — хотя бы одно).
3. Жмёт «Оформить заказ» → POST в Apps Script → таблица пополняется строкой,
   возвращается номер `NEO-0001`.
4. Корзина очищается, переход на `success.html`.
5. На success видит номер заказа и две кнопки (TG/MAX) — в обеих кнопках
   уже подставлено сообщение с номером заказа и составом.

## Что если Apps Script упадёт

Заказ всё равно оформится — выдаст временный номер вида `NEO-K8X3Z-TMP` и положит
данные в `localStorage['gg_pending_orders']`, чтобы данные не пропали. На success
покажется жёлтое уведомление, что нужно написать вручную.
