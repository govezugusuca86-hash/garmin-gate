## Шаг 1. Создать Telegram-бота для уведомлений

1. Открой в Telegram бот **@BotFather** → команда `/newbot`.
2. Дай боту имя и юзернейм (например, `neogar_orders_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH-xyzABC123...` — сохрани.
4. Открой **@userinfobot** → команда `/start` → он пришлёт твой `chat_id` (число).
5. **Важно:** напиши своему новому боту любое сообщение (например `/start`) — иначе бот не сможет тебе писать.

Если уведомления не нужны — пропусти этот шаг (заказы всё равно будут попадать в Google Sheets).

## Шаг 2. Развернуть Apps Script

1. Создай новую Google-таблицу или открой существующую.
2. Расширения → Apps Script.
3. Удали всё из `Code.gs`, вставь содержимое `Code.gs` из этого билда.
4. В начале файла заполни две константы:
   ```js
   var TELEGRAM_BOT_TOKEN = '7123456789:AAH-xyzABC123...';
   var TELEGRAM_CHAT_ID   = '123456789';
   ```
5. Сохрани (Ctrl+S).
6. **Тест уведомлений (опционально):** в редакторе выбери функцию `testTelegram` и нажми ▶ Запустить. Apps Script запросит разрешения — разреши. В Telegram должно прийти тестовое сообщение.
7. Развернуть → Новое развёртывание → ⚙ Тип → Веб-приложение.
   - Выполнять от имени: **Я**.
   - Доступ: **Все**.
8. Скопируй URL развёртывания (`https://script.google.com/macros/s/AKfy.../exec`).
9. Проверь URL: открой его в браузере → должно вернуть `{"ok":true,"service":"neogar-orders"}`.

## Шаг 3. Подставить URL в js/app.js

В `js/app.js` найди строку:
```js
window.ORDER_WEBHOOK_URL = 'https://script.google.com/macros/s/REPLACE_ME/exec';
```
Замени `REPLACE_ME` на URL из шага 2.

При изменении `Code.gs`: Развернуть → Управление развёртываниями → ✏️ → Версия «Новая» → Развернуть.
URL не меняется.

## Маршрут заказа

1. Пользователь в корзине → кнопка **«Оформить заказ»** → `checkout.html`.
2. Заполняет:
   - ФИ *
   - Телефон * (с маской `+7 (___) ___-__-__`)
   - Email (необязательно)
   - Галочка **«Нужна доставка»** → раскрывается блок (СДЭК/Яндекс + город + адрес)
   - Комментарий
3. Нажимает «Оформить заказ» → POST в Apps Script:
   - Заказ пишется в Google Sheets (15 колонок).
   - Уведомление в Telegram-бот тебе.
   - Возвращается номер `NEO-0001`.
4. Корзина чистится → переход на `success.html` с номером заказа и опциональными кнопками TG/MAX.

## Что произойдёт, если Apps Script упадёт

Заказ всё равно «оформится»: клиент получит временный номер `NEO-K8X3Z-TMP`, данные сохранятся в `localStorage['gg_pending_orders']`, на success появится жёлтое уведомление с просьбой написать в TG/MAX. Сообщение для мессенджеров уже готово — клиент жмёт кнопку и отправляет.

## Защита от спама и дублей

- **Honeypot:** скрытое поле `website`, его видят боты, но не люди. Заполнено → заказ молча отбрасывается.
- **Лок на клиенте:** повторная отправка в течение 10 секунд блокируется.
- **Дедупликация на сервере:** заказ с тем же телефоном и теми же товарами в течение 60 секунд → возвращается номер первого заказа, без записи второго.
